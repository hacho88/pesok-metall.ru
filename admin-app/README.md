# admin-app — админка pesok-metall.ru

Отдельное Next.js-приложение для поддомена `admin.pesok-metall.ru`. Конструктор
страниц (блоки, темы, контент, генерация по промпту) — без шапки и футера
основного сайта. Общается с основным сайтом через его API.

## Локальный запуск

1. Запустите основной сайт: `npm run dev` в корне репозитория (порт 3000).
2. Скопируйте `.env.example` в `.env` и при необходимости укажите
   `NEXT_PUBLIC_API_URL` (по умолчанию `http://localhost:3000`).
3. `npm install && npm run dev` — админка на `http://localhost:3001`.

## Что внутри

- `/` — список страниц (конфиги `PageConfig` из БД основного сайта).
- `/editor/[slug]` — визуальный редактор: палитра блоков, канвас с превью,
  инспектор свойств, темы, устройства, кнопка «По промпту» (генерация
  конфига через DeepSeek на основном сайте).
- `/products` — каталог: поиск, фильтры по категории/типу, создание и
  редактирование товаров (цены, остатки, характеристики, фото).
- `/categories` — категории каталога: создание, переименование, удаление.
- `/leads` — клиенты: заявки с сайта (чат, счёт, формы), смена статуса
  (новая → связались → квалифицирован → победа/потерян).
- `/advertising` — реклама: кампании Яндекс.Директ по товарам, ставки,
  лимиты, активность, клики/конверсии/ROI.
- `/fleet` — автопарк: машины для калькулятора доставки (груз, длина,
  подача, тариф за км).

Все данные — через API основного сайта (`/api/admin/*`).

## CORS

Основной сайт отдаёт CORS-заголовки для `/api/admin/*` из переменной
`ADMIN_ORIGIN` (по умолчанию `http://localhost:3001`). В проде на основном
сайте задайте:

```
ADMIN_ORIGIN=https://admin.pesok-metall.ru
```

## Деплой

Приложение независимо от основного сайта — деплойте на любой хостинг
Next.js (Vercel/Netlify) с переменной окружения:

```
NEXT_PUBLIC_API_URL=https://pesok-metall.ru
NEXT_PUBLIC_SITE_URL=https://pesok-metall.ru
```

DNS: поддомен `admin` → ваш хостинг.

## Примечания

- Код админки — копия модулей из `src/` основного сайта (types, block-schemas,
  icons, ui, блоки, админ-компоненты). При изменениях в основном репозитории
  синхронизируйте вручную.
- Старая админка на самом сайте (`/admin`) остаётся как fallback.
